## CSS
css를 인라인 방식으로 넣어보았다. 색과 배경색을 넣어보았다. 조금 더 복잡한 고급 꾸미기는 아마 따로 .css파일을 만들어서 하게 될 것 같다. 줄 전체에 배경색이 그어지는 게 좀 불편해서 더 찾아보았는데 태그 내에 글자 길이만큼만 배경을 설정하도록 조작할 수 있다고 해서 해보았다. 수정된 코드는 이렇다.

```html
<h1 style="
        display: inline;
        color: blue;
        background-color:aquamarine">자기소개서</h1>
```

### 선택과제 수행
- \#, \##, \### 태그 사용
- \`(백틱) 사용하여 코드블럭 생성
- 불릿 포인트 정리
- 언어소개 페이지에서 a태그로 index.html 연결
