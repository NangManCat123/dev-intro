## branch
- 메인이 되는 코드와 개발용 코드를 나누기 위해 branch가 사용된다.
- 실제 라이브로 가동되고 있는 것을 수정하긴 부담스러우니 살짝 빼서 개발한다음 나중에 다시 합치는 작업이다.

## CSS 
**Cascading Style Sheets**
- HTML에 스타일을 표현하게 해주는 언어이다.
- 수많은 문서에 각각 인라인 태그를 넣을 수 없으니 따로 css파일에서 스타일을 입힌다.
- 외부 스타일 < 내부 스타일 < 인라인 스타일의 우선순위가 있다.

## 색상을 정의하는 방법
- RGB의 값은 각각 0부터 255까지이고 이 각각의 RGB값을 16진수로 표현하면 두자리로 표현이 가능한데, 그걸 이어붙인게 hex code이다. 
- hex code 표현 방식을 평소에도 많이 봤고 어떤 체계인지 궁금했는데 간단한 거였다.

## margin, padding
- margin은 요소 바깥쪽 여백을 조작한다. 다른 요소랑 거리를 띄우는 용도이다.
- padding은 요소 안쪽 여백을 조작한다. 박스와 글자 사이 여백을 조정한다.
- 처음에 마진과 패딩을 줘보았을때 좌우가 떨어지는 건 좋은데 위라래로도 떨어지니 휑한 느낌이 들어 좌우 여백만 조작할 수는 없을까 하여 추가로 찾아보았는데, 특정방향 마진, 패딩만 조작할 수 있다는 것을 배워 페이지에 적용해보았다.
```css
    margin-left: 20px;
    margin-right: 20px;
    padding-left: 10px;
    padding-right: 10px;```
